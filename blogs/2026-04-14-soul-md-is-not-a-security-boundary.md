“The agent won’t do that. I told it not to in SOUL.md.” This is the most common response when someone asks how an OpenClaw agent is prevented from running rm -rf / , exfiltrating credentials via web_fetch , or sending customer PII to a Slack channel. The assumption is that an instruction in the agent’s identity file constitutes a security control.
